常见问题

为什么不用注册也能尝试解析？

页面默认使用公开的 FxTwitter 接口，把帖子 ID 发给第三方服务并读取返回的媒体信息。它不需要你的 X API Token，但可能限流、暂时不可用或更改接口格式。

iPhone 点击下载后如何保存？

页面会先尝试直接打开系统分享面板。若当前 Safari 不支持分享链接，再打开视频页面；此时可点击 Safari 的分享按钮并选择“存储到文件”。

我的下载记录会上传吗？

不会。最近使用的链接只写入当前浏览器的 localStorage，也可以随时点击“清空”删除。

可以下载受版权保护的内容吗？

请只保存你有权使用或备份的内容，并遵守来源平台的服务条款和当地法律。
